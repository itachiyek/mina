# Fotos

Gerichte mit einem `image`-Feld in `menu.js` bekommen eine Foto-Karte, alle anderen erscheinen als Textzeile.

```js
{ name: "Mina Bowl", image: "mina-bowl.jpg", price: 10.9, ... }
```
